# Student Management System

## Project Description
The Student Management System is a web-based application developed using HTML, CSS, and JavaScript. It allows users to add, view, and delete student records, including student names, enrollment numbers, and course details.

## Features
- Add student details
- View student records
- Delete student records
- Simple and user-friendly interface
- Responsive webpage design

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
Open the `index.html` file in a web browser.

## Project Purpose
This project is developed as part of the BCA Web Design and Development subject.
